# Week Planner AI

An AI-powered weekly planning application proof of concept (PoC) designed to help users organize and optimize their weekly schedules intelligently.

## Project Overview

Week Planner AI is a Next.js-based application that leverages artificial intelligence to assist users in creating, managing, and optimizing their weekly plans. The application aims to provide smart suggestions, task prioritization, and schedule optimization based on user preferences and patterns.

## Tech Stack

- **Framework:** Next.js 16 with App Router
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Linting:** ESLint
- **Package Manager:** npm

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the application.

## Development

- `npm run dev` - Start the development server
- `npm run build` - Build the production application
- `npm run start` - Start the production server
- `npm run lint` - Run ESLint
