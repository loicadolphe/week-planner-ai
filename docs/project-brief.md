# Week Planner AI

A weekly planning app that helps users set goals, pull work from Linear, and create a realistic weekly plan around meetings.

## MVP

The user can:

* Set weekly goals
* View work items from Linear
* Select tasks to include in the week
* Build a realistic weekly plan
* Later: connect Google Calendar and schedule tasks around meetings

## Principles

* AI should suggest plans, not automatically change calendars without approval.
* Deterministic code should handle scheduling constraints.
* AI should handle task breakdown, prioritisation, summaries, and overload detection.

## Stack

* Next.js App Router
* TypeScript
* Tailwind CSS
* PostgreSQL later
* Drizzle ORM later
* Linear API later
* Google Calendar API later
* OpenAI or Vercel AI SDK later
